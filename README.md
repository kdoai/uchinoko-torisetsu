# うちの子トリセツ

**学校で気づき、家庭で確かめ、一緒に育てる。**  
**子どもには冒険ゲーム、大人にはその子に合う関わり方が見えるAI。**

- **Google AI Studio アプリ**: https://ai.studio/apps/b7f98ee7-d180-433f-bb86-31fc19dd3cc8

---

## 概要

文部科学省の調査では、通常の学級に学習面または行動面で著しい困難を示す児童生徒が **8.8%** 在籍しています。しかし多くの困難は「学校だけ」または「家庭だけ」の断片的な観察では原因が見えにくく、支援の手がかりが見つからないまま子どもが自信を失ってしまう課題があります。

**「うちの子トリセツ」** は、小学校の **1人1台端末（GIGAスクール端末）** で、子どもが **『がっこう たんけん』**（2Dアドベンチャー＆3Dガチャ）として楽しく遊ぶだけで本人の困り感や得意な感覚を記録できるWebアプリケーションです。

子どもの冒険ログに加え、**家庭の観察・先生の所見・試行錯誤の記録**という **「4つの視点」** を **Google Gemini** が横断整理し、診断名をつけるのではなく **「明日から試せる具体的な工夫の仮説（その子だけのトリセツ）」** を提案します。

## 1クリック・デモモード（ログイン不要）

トップ画面の **「架空データで全画面を体験（デモ）」** ボタン、または以下のURLクエリから、架空データ（ひだまり小学校 2年1組・はる）を使って全ロールの画面とAI連携を即座に体験できます（Firestoreへの書き込みは発生しません）。

- **こども画面（『がっこう たんけん』2Dゲーム＆3Dガチャ）**: `http://localhost:3000/?demo=child`
- **保護者画面（家庭記録・相談メモ下書き生成・医療機関向けメモ出力）**: `http://localhost:3000/?demo=parent`
- **先生画面（4つの記録を並べる・Gemini仮説生成・授業で遊ぶ・氏名なしQR発行）**: `http://localhost:3000/?demo=teacher`
- **安全対応担当者画面（SOSシグナル隔離トリアージ・3段階対応手順）**: `http://localhost:3000/?demo=safety`

## 主な機能とAI活用・安全設計

### 1. 子ども向け：『がっこう たんけん』（Gemini A 連携）
- **2Dアニメーションマップ＆ミニゲーム**: 朝の教室、ふんすい広場、くまさんマーケット（おつかい計算ゲーム）、おとどけ広場、**Three.js による3Dガチャマシン**を搭載。
- **キャラクター「モモ」のやさしい深掘り（Gemini A）**: 子どもが「ちょっと たいへん」などを選ぶと、Gemini A が小1〜小3向けのひらがな・わかち書きで **最大2回・選択式のみ** のやさしい質問を生成。自由記述欄を設けず、入力負荷と個人情報混入を防ぎます。

### 2. 先生・保護者向け：4つの視点の横断整理（Gemini B 連携）
- **4つの記録を並べる**: ①子どもの冒険ログ ②保護者の家庭観察 ③先生の学校記録 ④試した工夫と子どもの手応え（「よかった／ふつう／あわなかった」）を一画面で比較。
- **Gemini B による関わり方の仮説提案**: 教室と家庭のギャップから背景要因の仮説と「明日試せる小さな工夫（例：興味のある恐竜イラスト入り穴埋めカード等）」を構造化JSONで提案。大人が採否を判断して試行サイクルを回せます。
- **保護者向け相談メモ＆受診時メモ**: 連絡帳・面談用の相談下書き生成や、公的相談窓口（教育支援センター・発達障害者支援センター等）の固定ディレクトリ案内、受診時にそのまま印刷・PDF保存できる事実整理メモを出力します。

### 3. 3つの安全ガードレール（非診断・非医療機器・児童安全隔離）
1. **非診断・非ラベリング**: Gemini のシステム指示・JSONスキーマ・サーバー側正規表現フィルタの三重チェックにより、病名・障害名の断定や医療助言を徹底排除。
2. **公的窓口のハルシネーション防止**: 相談先案内はAI生成に頼らず、検証済みの公的機関ディレクトリと受診メモ出力のみを提供。
3. **児童安全シグナルの完全隔離ルーティング**: 子どもが「おうちの ひとが こわい」等の安全に関わる選択肢を選んだ場合、AIの深掘りを即時停止し、**保護者画面には一切表示せず**、学校の **安全対応担当者（管理職・養護教諭等）専用画面** のみに暗号化・権限分離して通知します（189等の公的連携手順を併記）。

### 4. 全国の学級でそのまま使える展開設計
- **氏名なしQRカード発行・印刷**: 児童の氏名を含まないQRコードを1人1枚印刷し、学級全員で5分間の「たんけんタイム」として一斉実施可能（誰か一人だけを特別扱いしないインクルーシブ設計）。

## 技術スタック

- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Motion, Three.js (`three`), Lucide React, `qrcode.react`
- **Backend / API**: Node.js, Express (`server.ts`), Google Gen AI SDK (`@google/genai` - `gemini-2.5-flash`)
- **Database & Security**: Firebase Authentication, Cloud Firestore (`firestore.rules` によるロール別・安全報告隔離アクセス制御)

## ローカル起動手順

**必要環境:** Node.js (v20以上推奨)

1. 依存パッケージのインストール:
   ```bash
   npm install --legacy-peer-deps
   ```

2. 環境変数の設定:
   `.env.example` をコピーして `.env` を作成し、必要に応じて Gemini API キーおよび Firebase Web 設定値を記入します（未設定の場合でも、`?demo=...` のデモモードは全画面動作します）。
   ```bash
   cp .env.example .env
   ```

3. 開発サーバーの起動:
   ```bash
   npm run dev
   ```
   ブラウザで `http://localhost:3000` を開きます。
